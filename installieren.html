Vor dem Installieren

Creator Studio muss über eine HTTPS-Webadresse erreichbar sein, beispielsweise über GitHub Pages. Nur eine lokal geöffnete index.html oder eine ZIP-Datei auf dem Handy genügt nicht. Eine Anleitung zum Veröffentlichen findest du weiter unten.

EINMALIG EINRICHTEN

Noch keine Webadresse?

1. Auf GitHub hochladen

Erstelle ein öffentliches Repository, zum Beispiel creator-studio. Lade den Inhalt des Ordners creator-studio hoch, sodass index.html direkt im Hauptverzeichnis liegt.

2. GitHub Pages aktivieren

Öffne Settings → Pages → Build and deployment. Stelle Deploy from a branch, main und /(root) ein und speichere.

3. Deine Adresse öffnen

Nach der Veröffentlichung ist deine App unter einer Adresse wie https://DEIN-NAME.github.io/creator-studio/ erreichbar. Öffne genau diese Adresse auf deinem Smartphone.

4. Wie oben installieren

Wähle iPhone oder Android oben aus und führe die vier Schritte durch. Bei Updates genügt es, die Dateien im GitHub-Repository zu ersetzen.

Gut zu wissen

  • Die installierte App kann dank Offline-Cache nach dem ersten erfolgreichen Laden auch ohne Internet starten.
  • Deine Projekte werden lokal auf diesem Gerät gespeichert; es gibt keinen automatischen Abgleich zwischen Handy und PC.
  • Exportiere deine Daten unter Einstellungen → Backup, bevor du den Browser-Speicher löschst oder das Gerät wechselst.
  • Eine andere Webadresse oder ein anderer Browser kann einen separaten Datenbestand haben.

Probleme bei der Installation?

Installieren fehlt? Prüfe, ob du die echte HTTPS-Adresse geöffnet hast, nicht eine lokale Datei. Nutze auf dem iPhone Safari und auf Android möglichst Chrome.

Nur eine Verknüpfung? Manche Browser oder Android-Versionen legen statt einer vollständig installierten App einen Startbildschirm-Link an. Öffnen lässt sich Creator Studio trotzdem bequem über das Icon.

Änderungen nicht sichtbar? Öffne die Webseite erneut mit Internetverbindung; eventuell muss der Browser den Offline-Cache erst aktualisieren.
